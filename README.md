# Let Them Fight

A physics-based absurd AI-vs-AI battle simulator.

🧠 ## Overview

Let Them Fight is a single-player simulation game where both fighters are AI-controlled.
Players select characters, watch chaotic ragdoll battles, and experiment with random power-ups and arena events.

🧩 ## Core Features

* Physics-driven combat with procedural chaos
* AI-vs-AI fights (inspired by TABS & Shadow of War pit fights)
* Random power-ups and environmental events
* Campaign and sandbox modes

⚙️ ## Tech Stack

Unity (C#), **SOLID Architecture**, **Data-Driven Design (ScriptableObjects)**, **AI State Machine (State Pattern)**, and Physics-based interactions.
